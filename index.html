0

动手前 · 先量后动

这一步做不完就不要往下走。设备「变砖」绝大多数不是技术难，是这里跳了一步。

01

三查：这台机器到底能不能动

5–10 分钟

三个数缺一不可：方法支持到哪、你的机器出厂是什么、现在实际是什么。写下来再决定。

  1. 查上限：这套方法当前公开的系统上限是 13.6（作者 2026-10 自述，时效性极强——动手当天请重新确认，别用一个三个月前的数字）
  2. 查出厂：用序列号对照版本表。作者提到有一批序列号「标红需注意」，你的序列号落在里面就要格外小心；机身标签上的型号编码（另一份实测笔记记的是 F55B）是同批次判断的第二个线索
  3. 查实际：设置 → 系统 → 主机信息 → 系统软件，看实际版本。包装盒、卖家描述都不算证据
  4. 看已知样本：目前可查的成功案例有两个——视频作者 12.4、另一份实测笔记的 Slim 出厂 12.0（型号 F55B，2026-10 下单）。后者没说明还原了哪一份镜像，所以不能反推档位，但能确认 12.0 在可操作范围内
做完确认
三个数都写在纸上或这里：支持上限 / 序列号对应版本 / 系统实际版本。实际版本 ≤ 13.6 才继续。
卡住了怎么办
  • 实际版本高于上限 → 停手。降级比升级风险更大，视频也没给降级路径
  • 卖家说「能折腾」但系统显示更高 → 以系统为准，别信口头承诺
  • 序列号查不到对应版本 → 先做第 04 步的整机备份，等于给自己留了退路再试
注意
11.40 是一个例外：它不被 4.03 那份镜像支持（作者原话「除了 11.40 不支持之外」）。原因视频未说明，照录。
A

备料 · U 盘

U 盘要当两个用途：装恢复镜像、承接整机备份。装错了后面每步都会卡。

02

U 盘：容量、格式、文件摆放

10 分钟

这一步的坑不在技术，在路径层级和文件系统。

  1. 容量：要同时放下「整机备份」和「恢复镜像」。视频没给具体数字，另一份实测笔记建议 16GB 以上——但那是下限估计，整机备份加几份镜像很容易超。实际以第 04 步系统算出的所需空间为准，所以先别急着把 U 盘装满
  2. 格式化为 exFAT（作者明确强调）。格式化会清空，先把里面原有的东西导走
  3. 把作者提供的 PS5 文件夹整个拖到 U 盘根目录——是拖文件夹，不是拖里面的文件
  4. 其余插件文件另放根目录，不要塞进 PS5 文件夹里（两者用途不同，混放会读不到）
  5. 在电脑上「安全弹出 / 卸载」之后再拔（作者特意提醒「记得右下角卸载 U 盘后再拔下」）
做完确认
U 盘根目录同时能看到 PS5 文件夹和插件文件；文件系统显示 exFAT；电脑已安全卸载。
文件系统exFAT
PS5 文件夹位置U 盘根目录
插件文件位置U 盘根目录（与 PS5 文件夹同级）
卡住了怎么办
  • PS5 认不到 U 盘 → 先确认格式是 exFAT，再确认插的是后置 USB 口
  • 插件列表是空的 → 八成把文件放进子文件夹了，挪回根目录
  • 「安全弹出」后拔下仍提示未卸载 → 重新插一次，等系统提示可拔出再拔
B

保命 · 备份

整机备份是唯一的后悔药。这一步比越狱本身更容易被跳过，也最不该被跳过。

03

关掉四处自动更新开关

5 分钟

作者原话是「把 4 个可能触发自动更新系统的地方关掉」，但视频没有逐一点名。所以这里给你找法，不给你编名字。

  1. 在设置 → 系统里，把所有与「系统软件更新 / 自动下载 / 自动安装」相关的开关关闭
  2. 在设置 → 系统 → 省电（待机）相关项里，关闭待机状态下联网、后台下载
  3. 在账号 / 用户相关项里，关闭自动登录、自动同步之类会拉起联网的行为
  4. 凑齐四处，并在下面把你实际关掉的四项记下来（换机器或重装时你会需要这份清单）
做完确认
四处都关掉，且你记录了具体是哪四处。此后系统不应再自行弹出更新提示。

04

整机备份（勾选所有可选项）

15–30 分钟（看数据量）

  4. 等进度跑完 → 点 OK → 系统会再重启一次，回到系统
做完确认
备份完成并自动重启回系统；U 盘内能看到备份数据，大小与你确认时看到的一致。

C

落地 · 还原镜像

整个流程唯一「按版本分档」的地方。选错档就回到原版备份重来，不要硬试。

05

按版本选对那一份镜像，再还原

10–20 分钟

不是「最新版一键脚本」，而是「你的版本落在哪个区间就用哪份」。先选档，再动手。另注：后续的包可能已合并档位，见下面第 2 条。

你的系统版本落在哪一档？
  1. 设置 → 系统 → 备份与恢复 → 恢复
  2. 列表里会同时出现：你自己刚做的那份原版备份 + 若干份恢复镜像（视频当时是 4.03 / 12.20 / 13.40 三份，加自己那份共四份）
  3. 份数对不上别慌：另一份实测笔记明确注了一句「老高更新了新的文件，新的文件应该没有这么多选项」。你若只看到一两份镜像，先看包内附带的说明再决定，不要按本页的份数去硬凑
  4. 用下面的选择器确认你该选哪一份
  5. 选中 → 系统重启 → 进入恢复流程 → 再次重启 → 进入系统
  6. 进入系统后会有初始化流程，作者直接略过——你也先别急着设账号，先去配网（下一步）
做完确认
两次重启后进入系统，且系统信息里的版本与你选的档位相符；桌面上能找到 Y2JB 应用——另一份笔记把这一步直接叫作「恢复系统，Y2JB 安装」，找不到就说明包内文件没进机器，回第 02 步核对 PS5 文件夹是否整个在根目录。
卡住了怎么办
  • 选错档、机器行为异常 → 用你自己那份原版备份恢复，回到出厂状态再重来。这就是第 04 步存在的意义
  • 恢复列表里只有部分镜像 → 先确认是不是新版包合并了档位（见第 2 条），再回第 02 步检查 PS5 文件夹是不是整个放在根目录
  • 恢复完桌面上找不到 Y2JB → 这份镜像可能不含 Y2JB，回第 02 步核对包内文件；不要拿没核对过的镜像反复试
  • 恢复完卡在初始化 → 正常，初始化可以稍后再设，先把网络配好（下一步）
注意
视频这里有一处自相矛盾：04:18 作者口述「我的系统呢 13.40」，但 01:04 他明确说过自己机器是 12.4。两处不一致（可能是 OCR 误识，也可能是口误）。以你自己系统信息里的实际版本为准；如果正好落在 13.40 这个重叠边界上，两份都准备着，先试对应档。
D

配网 · DNS 指回本机

这一步最容易被误判成「坏了」。连不上网是设计意图。

06

把 DNS 设成 127.0.0.2，然后接受「无法连接 Internet」

5 分钟

目的只有一个：切断主机与官方服务器的自动通信（更新检查、遥测），避免版本被刷掉、避免带着改动联网被识别。

  1. 有线（推荐，作者以此为例）：插网线 → 设置 → 网络 → 设定互联网连接 → 有线 → 高级设置
  2. IP 地址用自动获取；DNS 改为手动，主 DNS 填 127.0.0.2
  3. 无线：不要点扫描列表里搜出来的那个 Wi-Fi（会直接连上，跳过 DNS 设置）→ 滑到最下面手动输入 SSID 和密码 → 先设 DNS 为 127.0.0.2 → 再连接
  4. 看到「无法连接 Internet」——这是预期结果，不是故障，因为 DNS 指向了本机、没有服务应答
做完确认
显示网络已连接，同时明确提示「无法连接 Internet」。两者同时成立才是对的。
IP 地址自动获取
DNS（主）127.0.0.2
DNS（备选写法）127.0.0.1（视频说两者都行）
卡住了怎么办
  • 无线时手快点了列表里的 SSID → 断开，删掉这个连接，回到「手动输入」路径重来
  • 提示 DNS 无效 / 无法保存 → 确认没在第 01 步之外的地方填了别的东西，主副 DNS 只填一个也可以
  • 一直显示已连接且能上网 → 不对，说明 DNS 没生效，回去检查是不是走了自动获取
注意
为什么统一用 .2 而不是 .1？作者的原话是「部分插件对 0.2 有执念，所以这统一用 0.2」——这是兼容性选择，不是技术必要性。照抄 .2 最省事。
E

越狱 · 跑 Y2JB

真正「几秒钟」的部分只有这一段——前面全是准备。

07

运行 Y2JB，跑完码

1 分钟

作者的说法：每次开机运行 Y2JB，几秒钟即可完成。

  1. 把 U 盘插到 PS5 后置 USB 口（作者强调后置，别用前面板）
  2. 打开 Y2JB
  3. 第一次运行会提示重启 → 同意，让它重启
  4. 重启回系统后，再运行一次 Y2JB
  5. 它会自动跑码，等它跑完，不要中途操作手柄
做完确认
跑码完成 = 越狱成功；紧接着会自动安装并进入 Payload 插件管理器。此时界面仍是英文/日文属正常——中文由「中文汉化补丁」这个插件提供，要到第 10 步打开它才生效，别拿「菜单变中文」当这一步的判据。
卡住了怎么办
  • 跑码中途失败 → 重启后再试一次（这类注入对时机敏感，重试是常规操作）
  • 反复失败 → 先别硬试，改用 WebKit 备用方案（见第 09 步）
  • 重启后 Y2JB 不见了 → 检查 U 盘是否还在后置口、PS5 文件夹是否还在根目录
  • 跑完码界面还是英文或日文 → 正常。中文要等第 10 步打开汉化补丁，不是这一步失败
08

让插件管理器认出 U 盘里的插件

2 分钟

默认应该自动显示；不显示有两个开关要动，还有一个「报错」要无视。

  1. 管理器默认会列出 U 盘内的所有插件
  2. 看不到插件 → 进「设定」，勾选「USB 检查」
  3. 然后按三角键刷新
  4. 等大约 10 秒（作者原话「大概 10 秒左右，不要着急」）
  5. 出现一条报错 → 不用管它（作者原话）
做完确认
插件列表里能看到 U 盘中的插件文件，且能选中执行。
卡住了怎么办
  • 列表一直空白 → 确认 U 盘在后置口、插件在根目录，再拔插一次后刷新
  • 刷新后仍不出现 → 回第 02 步核对文件层级（最常见就是放进了子文件夹）
  • 看到报错就想修 → 不必，这条报错在流程里是预期内的
F

插件 · 装上并排好顺序

这一步决定「每次开机要不要手动折腾」。顺序和间隔比插件本身更重要。

09

记下主机 IP，再装一套备用方案

2 分钟

两件事都很小，但都只做一次就够用很久。

  1. 设置 → 系统 → 主机信息，把 PS5 的 IP 地址记下来——后面远程管理要用
  2. 把 WebKit 也装上：装完桌面上是一个小地球图标
  3. 它的作用就一句话：「如果 Y2JB 一旦有问题，还有另外一套方案可用」
做完确认
IP 已记下；桌面上出现小地球图标且能打开。
PS5 IP
注意
IP 是 DHCP 分的，重连网络或换路由器后可能变。远程管理连不上时，先回来重新确认这个数。
10

装齐其余四个插件（含汉化补丁）

5 分钟

作者逐个说了它们各自管什么。第 11 步要排四个插件的加载顺序，所以这里必须四个都装上——漏一个，自动加载那一步就排不齐。

  1. 中文汉化补丁 —— 在插件管理器里打开它，界面才会变中文。另一份笔记的顺序也是「进入插件管理页面 → 再打开中文汉化补丁」。它同时是第 11 步自动加载的第 2 项，别当成可选项跳过
  2. kstuff —— 名字就是用途：对 fpkg 文件的支持。11.6 以下的系统可以直接运行 fpkg
  3. ShadowMP —— 自动扫描并安装、游戏库管理、文件管理器，按需开启
  4. NanoDNS —— 让 DNS 继续指向本地，同时避免连到官方服务器导致机器被 Ban；装上之后就能按域名决定放行什么
  5. 每装一个就打开一次，确认不闪退、不报错
做完确认
四个插件都能正常打开；界面已变成中文（说明汉化补丁生效）；NanoDNS 生效后，网络状态不再是「无法连接 Internet」而可以正常联网（同时官方域名被挡）。
注意
这五个工具（Y2JB / 汉化补丁 / kstuff / ShadowMP / NanoDNS）本站不做任何安全验证：不去访问、不下载、不评价。它们无签名、无审计、要求在本机执行权限、由个人维护——请一律按「未知来源的可执行文件」对待。
11

导入内部存储，排好自动加载的顺序与间隔

10 分钟

这一步做完，以后开机只要点一下 Y2JB，其余全自动。

  1. 把常用插件导入 PS5 内部存储 —— 之后就可以不插 U 盘（作者原话「摆脱 U 盘的束缚」）
  2. 设置自动加载顺序：NanoDNS → 中文补丁 → kstuff → ShadowMP
  3. 每个之间设 3 秒延迟（作者对最后两个明确说了「再 3 秒」）
  4. 重启 PS5 测一次：开机 → 点 Y2JB → 看是否按序自动跑完
做完确认
重启后几秒完成越狱，四个插件依次跑完、每个间隔约 3 秒、没有「扎堆」报错。作者测完的原话是「好了没问题」。
加载顺序NanoDNS → 中文补丁 → kstuff → ShadowMP
间隔3 秒
远程管理地址http://<PS5的IP>:8084
卡住了怎么办
  • 有时成功有时失败 → 说明是资源竞争，把间隔从 3 秒加长，比换更快的盘有效
  • 顺序每次都被打乱 → 重排后保存，再重启确认一次是否被持久化
  • 开机没自动跑 → 确认自动加载开关是开的，且插件已在内部存储而不是 U 盘
注意
IP:8084 这个远程登录口要当风险记，不是当功能记：它让电脑浏览器随时能管 PS5 上的 payload，但这是一个无认证的本地服务。同网段里谁知道 IP 谁就能连。
G

硬件 · M.2 与摆放

这一段与「折腾」无关的部分，所有 PS5 用户都适用。

12

加装 M.2 盘

15 分钟（含拆装）

三条硬约束先记住：PCIe 4.0、最长 22110、必须散热片。

  1. 拆：翻到背面，短侧那边可以掰开盖板，用螺丝刀拧开护板
  2. 选盘：PS5 要求 PCIe 4.0（作者说「貌似有办法兼容 3.0」，但他没研究，你也别赌）；长度最高 22110，共支持 5 种尺寸
  3. 装散热片：作者说「最好是装个 M.2 盘的散热片，增加稳定性」——弹舱内有散热孔，风扇能把热带走
  4. 拧上护板固定，盖上盖板
  5. 设置 → 存储，把 M.2 盘格式化一下才能用
  6. 之后可选择游戏安装在内置硬盘还是内置扩展的 M.2 盘
做完确认
设置 → 存储里能看到这块 M.2，显示已格式化，并可被选为安装位置。
卡住了怎么办
  • 装完认不到盘 → 先确认是不是 PCIe 4.0、长度是否超 22110、有没有插到底
  • 认到了但提示需格式化 → 正常，去存储里格一次
  • 长时间读写掉速 → 散热片没装或没贴紧

支架，以及为什么建议平放

3 分钟

视频最后一条，也是最容易被忽略的一条。

  1. 简易支架：插在 PS5 底侧中缝，每个支架插入一对小孔中
  2. 3D 打印定制支架：根据底盖弧度，从头上滑入支架卡槽内，再调整位置
  3. 摆放方式：平放优于竖放
做完确认
机器稳固不晃；底部进风不被桌面挡住。
注意
平放的理由和折腾无关：作者原话是「为了防止处理器导热液金泄漏，平放还是最好的选择」。这是 PS5 这一代的物理风险点，任何 PS5 用户都适用。定制支架的意义是离桌面更高、更利于空气流通。
